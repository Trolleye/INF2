# Hero Survivors - LibGDX Game Project

## DISCLAIMER

The hitbox system needs tuning as well as the camera updates.

## Overview

Hero Survivors is a 2D game developed in Java using the LibGDX framework as part of the Information and Networking Technologies study program.

The project demonstrates object-oriented programming, game loop architecture, input handling, collision detection, asset management, and game state management.

## Features

* Player movement and controls
* Collision detection
* Enemy/NPC interactions
* Score system
* Multiple game states (menu, gameplay, game over)
* Sound effects and music
* Asset management using LibGDX

## Technologies

* Java
* LibGDX
* Gradle
* Git

## Project Structure

```text
core/      - Shared game logic
lwjgl3/    - Desktop launcher
assets/    - Textures, sounds, fonts
```

## Getting Started

### Requirements

* Java 17+
* Gradle

### Run the Project

On Windows:

```cmd
git clone https://github.com/Trolleye/Hero-Survivors.git
```
and open releases/Hero-Survivors.jar

To build the project run:

```cmd
gradlew.bat desktop:dist
```
or
```bash
./gradlew desktop:dist
```
